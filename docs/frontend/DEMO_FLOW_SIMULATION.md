# DEMO FLOW (≈6 minutes)

**Quick path:** click **START DEMO** in the customer navbar — a 15-step guided tour drives the real runtime through customer and admin pages.

**Manual path**
1. Customer `/events/ai-frontier-mumbai-2026` — 500 seats, huge demand. Open ☰ → **ADMIN ACCESS**.
2. Sign in `admin@fairdrop.demo` / `FairDrop@2026` → Overview (PREPARED).
3. **Drop Control** → *Open Pre-Queue* (commitment published). Raise the clock in **Traffic → Load Lab** (×4/×8).
4. **Attack Lab** → scenario *Distributed*, press *Start — reset & launch* (or *Inject into running drop*). Watch the chain attack → detection → mitigation → queue → admission → allocation.
5. **Intelligence → Detection / Campaigns / Risk Signals** — advisory ML, deterministic policy, coordinated groups.
6. **Drop Control** → *Close Pre-Queue* → **Admission → Pre-Queue** (eligible pool) → *Randomize* → **Randomization** (seed chain, recompute PASS) → *Start Admission*.
7. In another tab or via the guided tour, the customer joins and buys a ticket; **Allocations** shows CONFIRMED + HELD + AVAILABLE = TOTAL and the allocation stream.
8. **Fairness → Fairness Lab** → *Run counterfactual experiment* → World A / World B / naive baseline; **Allocation Advantage** shows AAA.
9. **Fairness → Verification** — untouched bundle verifies; tampered seed/list/position are detected.
10. **Operations → Incidents, System Health (honest SIMULATED labels), Reports** → download the drop report.
11. Log out → `/admin/login`.

Tip: use one browser tab (client-side navigation) to keep customer and admin on the same in-memory drop.
